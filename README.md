# etchspan

Etch encode/decode helpers for span payloads in pipelines.

**Site:** https://theworker02.github.io/etchspan/

## Install / run

```bash
git clone https://github.com/theworker02/etchspan.git
cd etchspan
node src/cli.js
node --test
```
